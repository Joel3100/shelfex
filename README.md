# Shelfex 📚

**Reformed Library App** — a digital library and reading tracker to organize, search, and manage your personal book collection.

🔗 **Live Demo**: [shelfex-library.vercel.app](https://shelfex-library.vercel.app)

## Features

- Mark books as read
- Search books by name
- Filter books by author and category

## Tech Stack

- **Frontend**: React + Vite
- **Styling**: Tailwind CSS
- **Linting**: ESLint

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

\`\`\`bash
git clone https://github.com/Joel3100/shelfex.git
cd shelfex
npm install
npm run dev
\`\`\`

The app will run at `http://localhost:5173`.
